\section{Dataset Formulation and Bias Mitigation}
\label{sec:app1_datasets}

\paragraph{Data Curation and Preprocessing}
For now we use IN22-Gen \citep{gala-etal-2023-indictrans2}. It has 1{,}024 sentences drawn from Wikipedia and other web sources, translated into all 22 scheduled Indian languages, together with their English source. The sentences cover 13 broad categories: culture, economy, education, entertainment, geography, government, health, industry, legal, news, religion, sports, and tourism. We use all 1{,}024 sentences for each of the 23 languages.

\paragraph{Sample Bias Mitigation}
IN22-Gen is n-way parallel, so every language carries the same content. Differences between languages therefore could come from script, tokenizer, translationese and model. The 13 categories cover general language use instead of one domain, so the samples are not restricted to any single domain. For the token view, since IsoScore depends on the number of tokens, we draw $N = 16{,}000$ tokens for every language and model, to keep the number of tokens uniform across languages and models. These tokens are drawn uniformly at random from all non-special tokens of all 1{,}024 sentences, with a fixed seed. Special and padding tokens are excluded from the token view.

\paragraph{Bottlenecks Encountered}
The number of tokens for the same 1{,}024 sentences varies widely. With the Gemma tokenizer, it ranges from 33{,}896 for English to 284{,}181 for Manipuri (Meitei), 8.4 times as many. Keeping all hidden states for such languages does not fit in memory, so the sampled token positions are fixed before inference and gathered batch by batch. 

\paragraph{Dataset Extensions and Distinctions}
Prior isotropy studies use English corpora \citep{ethayarajh-2019-contextual,rudman-etal-2022-isoscore}. We extend the analysis to 22 Indic languages in 12 scripts with an aligned English reference. The pipeline also supports IN22-Conv, FLORES+, Sangraha Verified, IndicCorp v2, Wikipedia, and IITB IndicMonoDoc. These add conversational text, other parallel text, and native monolingual text, which will separate translation effects from language effects in later runs.
