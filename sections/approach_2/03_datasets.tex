\begin{itemize}
\item FiQA2018: Financial opinion question answering. Contains 57,638 document passages and 648 short user queries (mean 10.9 words). Ground truth maps 1,706 relevant pairs (average 2.63 relevant passages per query).
\item ArguAna: Counter-argument retrieval. Contains 8,674 candidate arguments and 1,406 queries with strictly 1-to-1 relevance mapping. Both queries (mean 193.6 words) and documents (mean 167.2 words) consist of multi-sentence argumentative passages.
\item SCIDOCS: Scientific citation search. Contains 25,657 candidate abstracts and 1,000 title queries. Ground truth provides 29,928 relevance pairs (average 29.93 relevant citations per query).
\item STSBenchmark: Canonical sentence similarity synthesis spanning news, image captions, and web forums across 1,379 sentence pairs. Human labels range from 0.00 (unrelated) to 5.00 (semantically equivalent) with mean 2.61 and standard deviation 1.52.
\item SICK-R: Sentence relatedness across 9,927 pairs. Sentences average 9.6 words and probe lexical entailment, contradiction, and semantic relatedness. Scores range from 1.00 to 5.00 (mean 3.53, standard deviation 1.02).
\item STS22.v2: Long-form cross-domain semantic similarity across 197 pairs. Text length averages 461.1 words (median 340.0 words, maximum 4,412 words), testing semantic matching across extended multi-paragraph contexts.
\end{itemize}

\paragraph{Sample Bias Mitigation and Experimental Controls}
To eliminate confounding factors between models and tasks, we implement two controls:
\begin{itemize}
\item Uniform Sequence Length Ceiling: Evaluated models possess widely varying context limits (2,048 tokens for EmbeddingGemma; 32,768 for Qwen3-Embedding and Gemma-3-1b-pt; 262,144 for Qwen3.5-0.8B-Base). To eliminate truncation bias, we fix a uniform sequence limit of $\min(2048, 32768, 262144) = 2,048$ tokens. Over 99\% of benchmark texts fall well within 2,048 tokens, ensuring zero document truncation while preventing asymmetric context window advantages.
\item Decoupled Calibration Manifolds: In asymmetric retrieval, user queries arrive dynamically at search time. Calibrating covariance parameters on queries would introduce transductive test-set leakage. We enforce strict asymmetric calibration: empirical mean $\mu_D$, covariance $\Sigma_D$, and transformation matrix $W_D$ are computed strictly on the document corpus $D$, and applied identically to incoming queries $Q$. Transformed representations are projected onto the unit hypersphere via L2 normalization. In symmetric STS, both sentences in each pair originate from the identical distribution and are pooled jointly.
\end{itemize}

\paragraph{Data Bottlenecks and Technical Handling}
Two data-level bottlenecks were identified and resolved:
\begin{itemize}
\item Zero-Length Input Clamping: FiQA2018 contains 38 empty document texts. When tokenized with right-padding, these produce attention mask sums of zero. Unclamped sequence indexing causes negative index wrapping (indexing token $-1$), capturing trailing padding vectors rather than hidden states. We clamp active sequence lengths to $\max(0, \sum \text{mask} - 1)$ to guarantee valid hidden state extraction.
\item Full-Corpus Memory Allocation: Estimating sample covariance matrices on 57,638 passage vectors in FP32 requires accumulating a $d \times d$ outer product matrix. To avoid GPU threadgroup staging limits on Apple Silicon unified memory, covariance accumulation and symmetric eigendecompositions ($\Sigma = U \Lambda U^\top$) are executed on the host CPU, with eigenvalues clamped to zero to enforce positive semi-definiteness.
\end{itemize}
